ddrescue lab notes
==================

Patient: pattern image, 64 regions of 1 MiB, each region a
repeating self-naming line; per-region SHA-256 in t01.

Damage: LD_PRELOAD shim (fakedead.c) returning EIO for reads
touching declared ranges of the patient file:
  10485760-11534336   (MiB 10,      1 MiB)
  32505856-32514048   (MiB 31 start, 8 KiB)
  52428800-55574528   (MiB 50-52,   3 MiB)
Total dead: 4,202,496 bytes.

First pass (-n): 62,906,368 B rescued (93.74%), 73 errors.
Mapfile showed trimming already done (512 B bad splinters
at each dead edge, non-scraped interiors). Lesson: -n skips
scraping only.

Interrupt test: 128 MiB patient, --max-read-rate=4MiB,
SIGINT at 19.04%. Resume opened at ipos 25559 kB - nothing
re-read. Finished with one bad block of exactly 1 MiB.

Second pass (-r2): scraping + two retries against still-
dead ranges: 24,618 read errors, zero extra bytes. Final
mapfile: three bad blocks of exactly the declared sizes.
Pessimistic case - the shim never relents; real marginal
sectors are what retries exist for.

Accounting (independent script, 4096 B blocks):
  recovered 62,906,368 B, lost 4,202,496 B - exactly the
  declared damage, nowhere else. Region checksums differ
  only in 10, 31, 50-52.

ddrescuelog: -D returns 1 on finished-but-lossy, 0 only on
perfect. -d deletes the mapfile only in the perfect case.

Merging: copy A dead at MiB 10, copy B dead at 50-52, same
output+mapfile. Plain run from B changed nothing (bad
blocks are settled). With -r1, B filled A's hole: final
comparison 100.00%, zero differing blocks.

False start worth remembering: the first shim build
wrapped only classic open/read names; ddrescue opens via
the fortified __open64_2, sailed past it, and "rescued"
100% of a dead file. The shim's own proof test (head under
the shim stopping at byte 10485760) is what caught it.
Verify the rig before the rescue.

Environment limits: sandbox forbids loop devices and
mknod entirely (t90), hence files + shim. Real-hardware
behaviour is documented, not measured, in chapter 10.
Binaries: genuine gddrescue 1.27-1 .deb, unpacked (apt
state was shared with parallel builders).
